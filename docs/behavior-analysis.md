# 行为数据导出与分析

## 会话文件

每次运行生成一个独立的会话编号。同一参与者重跑也生成新编号。会话目录位于采集端的 `data/`，包含 UTF-8 BOM 编码的三个 CSV 和 UTF-8 编码的 `meta.json`。尚无记录的表保留表头。仓库、PR 和 CI 使用合成数据或脱敏汇总。

每次保存先在临时目录写完整文件，再逐个替换，最后替换 `meta.json`。读取时先取元数据，再用同一批 CSV 原始字节计算 SHA-256 和解析数据，核对 `数据表` 中的摘要及行数。运行中读取可能跨到两次保存，校验不一致时可在保存完成后重新读取。持续不一致的文件应保留原档并记录为待核对。

| 文件 | 一行代表 | 主键或关联键 |
| --- | --- | --- |
| `trials.csv` | 一次实际呈现的题，包括练习 | `会话编号 + 试次编号` 唯一。区段内还有 `区段内序号` |
| `intervals.csv` | 一次完成或记录了中断的区段 | `会话编号 + 阶段 + 区段` 唯一 |
| `probes.csv` | 一次已确认的滑块报告 | `会话编号 + 探测编号` 唯一。也有该报告之前区段的 `阶段` 和 `区段` |
| `meta.json` | 一场会话的当前记录 | `会话编号` 对应同目录三张表 |

正式区段使用 `阶段=main`，区段编号在会话内从 1 连续编号。组块号和末段位置来自该会话的 `正式调度`，区段号跨组块连续。练习 `prac1`、`prac2` 的单题独立呈现，`区段` 留空。`prac3` 的区段号从 1 重新编号。快跑可由 `运行参数.DEBUG_FAST` 识别，正式分析只选采集协议对应的会话。

把试次和探测分别以 `会话编号 + 阶段 + 区段` 左连接到区段表，检查关联为多对一，再核对组块。与元数据关联时用 `会话编号`。保留 `被试` 作为参与者层标识，重复场次仍属于同一参与者。异常发生在区段记录形成前时，已经写入内存的试次可能在导出中找不到对应区段。合表时报告这些行和来源会话，再从需要区段信息的分析中排除。

`导出版本` 标识字段契约。`代码版本`、脚本与模块的 SHA-256 标识实际运行的实现。`运行参数` 及 `参数SHA256` 记录配置，参数摘要取排序键、紧凑分隔符和 UTF-8 编码的 JSON。`正式调度` 记录来源提交、A/B 序列、每段窗长、预定来源及探测位置。分析结果应保留这些版本信息。

## 字段与统计口径

| 字段 | 口径 |
| --- | --- |
| `反应时` | 有效键按下时刻减目标翻屏时刻，单位为秒，保留计算结果精度。绝对时间戳以 PsychoPy 日志时钟计秒，在 CSV 中显示六位小数 |
| `作答状态` | `responded` 为本题翻屏起至区段截止前收到的有效键。`timeout` 为截止未答。`interrupted` 为本题作答被中断 |
| `可作答时长s` | 本题目标翻屏到原定截止之间的时间。用于核对区段尾部可用作答时间 |
| `正确` 与 `过快` | 正确按键记 1，错误按键或普通超时记 0，被中断且未答留空。`过快` 在有 RT 时标记 RT 小于 0.25 秒，未答时留空 |
| `试次数`、`作答数`、`正确数`、`截止未答数` | 分别统计已呈现、有效按键、答对和普通超时。中断未答的题计入呈现数 |
| `正确率` 与 `一致比例` | 导出的正确率以已呈现且未被中断的试次为分母，含普通超时。区段一致比例以所有实际呈现的试次为分母。分母为 0 时留空 |
| `区段状态` 与 `中断阶段` | `completed` 和 `interrupted` 区分完整与中断区段。后者有中断阶段和时间戳。反馈显示中退出的区段可已结算，仍标记为中断 |
| `效能类型`、`效能概率`、`得分来源` | `效能类型` 是预定的 `performance` 或 `random`。`效能概率` 当前留空，作者逐段概率尚未取得。`得分来源` 与 `区段得分` 随实际结算写出，未结算留空，已结算 0 分保留 |
| `探针类型`、`评价值` | 区段反馈后采集的 0–100 主观评分。题型是 `efficacy` 或 `reward`。预计的位置列在元数据中，已提交的报告列在 `probes.csv` |

元数据原有的 `区段数` 统计正式阶段已结算区段。`完整区段数` 和 `中断区段数` 按正式区段状态分别计数。快照的三个 CSV 优先用于核对明细和计数。

## 学习模型和行为分析

对正式区段按会话和区段号排序。实际显示的计分来源是效能学习的反馈，表现记 1，随机记 0。实际显示的区段积分是奖赏量反馈。区段没有结算时保留缺失，并记录缺失反馈在模型里的处理。对反馈中断的区段记录显示时长及纳入标准。主观探测行按相应区段关联到区段反馈之后的估计。[Study 2 学习模型](https://doi.org/10.1093/cercor/bhac215) · [作者区段汇总](https://github.com/igrahek/LFXC_EEG_2022/blob/eaebcb7a348109f20606a87f2210d3bb59bc7bf7/Analyses/Experiment2/Stats/brms/Experiment2_brms_models.R#L133-L150)

解释当段的反应时、正确率或 DDM 参数时，用该段**反馈前**的效能预期和奖赏预期。具体做法是把学习模型在前一段结束时的更新结果关联到下一段。首段的初始值或缺失处理写入分析方案。奖赏学习输入为积分量，若做归一化或标准化，记录原单位、转换公式和计算范围。模型复核时同时检查当前窗长和区段内一致比例。行为 RT 与正确率的分析样本应写清所用作答筛选，另报告各窗长的截止未答率。可核对作者的分析结果与本项目为质量检查保留的区段正确率。[作者反馈前变量](https://github.com/igrahek/LFXC_EEG_2022/blob/eaebcb7a348109f20606a87f2210d3bb59bc7bf7/Analyses/Experiment2/Stats/brms/Experiment2_brms_models.R#L581-L586) · [行为回归](https://github.com/igrahek/LFXC_EEG_2022/blob/eaebcb7a348109f20606a87f2210d3bb59bc7bf7/Analyses/Experiment2/Stats/brms/Experiment2_brms_models.R#L1333-L1360)

## DDM 准备与区段尾部

1. 从匹配到区段的正式试次中挑 `作答状态=responded`、有效按键和有限的秒制 RT。核对 `0 ≤ RT < 可作答时长s`。保留完整原始表，按阶段、状态和窗长记录排除数量。预先说明是否排除中断区段内已经有效作答的题。
2. 论文描述排除低于 250 ms 的反应。作者公开预处理脚本使用严格的 `250 < RT < 2000 ms`，并在 HDDM 输入时保留正确和按干扰词键的错误，将原数据的毫秒换成秒。复现这一版筛选时，本项目直接用秒制 `0.25 < RT < 2.0`。按元数据中的颜色—词与颜色—按键表，判断错误键是否是当前字义对应键。记录是否采用各项筛选及各步骤排除量。[论文 DDM 方法](https://doi.org/10.1093/cercor/bhac215) · [作者 RT 筛选](https://github.com/igrahek/LFXC_EEG_2022/blob/eaebcb7a348109f20606a87f2210d3bb59bc7bf7/Analyses/Experiment2/Stats/brms/Experiment2_brms_models.R#L588-L597) · [错误分类](https://github.com/igrahek/LFXC_EEG_2022/blob/eaebcb7a348109f20606a87f2210d3bb59bc7bf7/Analyses/Experiment2/Stats/brms/Experiment2_brms_models.R#L193-L197) · [HDDM 数据导出](https://github.com/igrahek/LFXC_EEG_2022/blob/eaebcb7a348109f20606a87f2210d3bb59bc7bf7/Analyses/Experiment2/Stats/brms/Experiment2_brms_models.R#L824-L845)
3. 区段尾部可用作答时间因题而异。短剩余时间会优先截去较慢反应。拟合前按窗长和一致性报告各题可作答时间及截止未答率。只拟合已作答的常规 DDM 时，结果条件于有效作答。预实验可比较限制到共同可作答时长的敏感性分析，或评估能按各题截止时间处理右删失的模型。截止未答留在缺失和时限诊断中。

## 旧会话与回归验证

旧版会话缺少 `导出版本`、独立会话编号或部分空表。导入旧数据时为每个原始会话目录分配并保留唯一的导入编号，先按 `阶段 + 区段` 在会话内关联，以 `插入位置` 匹配旧版探测表。旧版 RT 也使用秒制。作答状态可从反应键、RT 和试次中断标记重建。旧表记录的绝对时间戳和 RT 有舍入精度，无法还原边界附近的完整时间差。

在 PsychoPy Studio 的 Python 环境下运行 `python tests/check_behavior_export.py`。它用合成输入验证同一被试重跑、空表、区段关联、秒制 RT、探测和中断记录，并模拟替换文件中途失败，核对摘要能识别混合快照。
